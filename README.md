# 🎓 Coursify

Plataforma web para venda e gerenciamento de cursos online, desenvolvida com **Angular** no frontend e uma estrutura de backend integrada ao projeto.

O Coursify foi desenvolvido com foco em criar uma experiência simples e organizada para usuários que desejam encontrar, visualizar e adquirir cursos online.

---

## 📌 Sobre o projeto

O **Coursify** é uma aplicação web voltada para o mercado de educação online.

A plataforma possui uma interface moderna e responsiva, organizada para facilitar a navegação entre os cursos e apresentar as informações de forma clara ao usuário.

O projeto também possui uma estrutura de **backend**, permitindo a separação entre a aplicação frontend e os serviços responsáveis pelo processamento dos dados.

---

## 🚀 Funcionalidades

Entre os recursos presentes no projeto estão:

* 🎓 Catálogo de cursos

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de iniciar, certifique-se de possuir instalado:

* [Node.js](https://nodejs.org/)
* NPM
* Angular CLI

Para verificar as instalações:

```bash
node --version
npm --version
ng version
```

---

### 📥 1. Clone o repositório

```bash
git clone https://github.com/davisoares011/Coursify-Web
```

Entre na pasta do projeto:

```bash
cd coursify-web-5
```

---

### 📦 2. Instale as dependências

```bash
npm install
```

---

### ▶️ 3. Execute o frontend

```bash
ng serve
```

Após iniciar o servidor, acesse:

```text
http://localhost:4200/
```

A aplicação será atualizada automaticamente sempre que houver alterações nos arquivos do projeto.

---

## 🔧 Build

Para gerar uma versão de produção:

```bash
ng build
```

Os arquivos compilados serão disponibilizados na pasta de build configurada pelo Angular.

## 🧪 Testes

## 🎯 Objetivo

O principal objetivo do Coursify é aplicar conhecimentos de **desenvolvimento web, arquitetura de aplicações, componentes, serviços, APIs e gerenciamento de dados** na construção de uma plataforma de cursos online.

Além de funcionar como projeto de desenvolvimento, o Coursify também serve como projeto de **portfólio**, demonstrando a aplicação prática das tecnologias utilizadas.
